# Deniel John Prado — Portfolio

A monochrome, editorial personal portfolio built with Next.js 16, Tailwind CSS, and GSAP. Project entries live in `app/page.tsx`, making it easy to replace the sample work with real case studies.

## Local setup

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Codespaces

1. Open the repository on GitHub and choose **Code → Codespaces → Create codespace on main**.
2. In the Codespaces terminal, run `pnpm install` and then `pnpm dev`.
3. Open forwarded port `3000` from the **Ports** panel.

## Deploy to Vercel

Import the repository at [vercel.com/new](https://vercel.com/new), keep the detected Next.js settings, and select **Deploy**. Vercel will install dependencies and run the build automatically. You can also connect the repository in the Vercel dashboard for deployments on every push.

No environment variables are required.
